# Level-star tier icons

Five transparent 256 × 256 PNGs cut from `Five-Tier Rounded Star Icon Set-Photoroom.png`
(sheet layout: tiers 1-2-3 on top, 4-5 below). Each tier covers three student levels;
`src/lib/level-icons.js` maps level → tier with `ceil(level / 3)`.

| File | Levels | Look |
| --- | --- | --- |
| `star-tier-1.png` | 1–3 | Copper |
| `star-tier-2.png` | 4–6 | Stone |
| `star-tier-3.png` | 7–9 | Silver |
| `star-tier-4.png` | 10–12 | Pale gold |
| `star-tier-5.png` | 13–15 | Bright gold |
