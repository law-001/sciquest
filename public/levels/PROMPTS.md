# SciQuest level icon progression

15 standalone transparent PNGs for the student-level indicator. The files are
named `level-01.png` through `level-15.png` and are rendered by
`src/lib/level-icons.js`.

## Shared generation prompt

Create one standalone 2D vector-style game UI level icon in a matched
15-stage star progression. Use a clean, cute, polished flat style with subtle
gold-to-orange gradients, a thick clean warm-dark outline, centered framing,
and a transparent background. Keep the broad five-point-star proportions and
visual language consistent across every level. No text, numbers, UI cards,
logos, or watermark. It must remain clear at 48–96px.

Palette: `#FDE047`, `#FACC15`, `#F97316`, `#5B4530`, and `#FFF7D6`.

## Progression

| Levels | Treatment |
| --- | --- |
| 1–2 | Simple outlined gold star, then a stronger highlight. |
| 3–4 | Polished star with controlled surrounding sparkles. |
| 5–9 | Milestone ring, then increasingly prominent rings, glow, and sparkles. |
| 10 | Major milestone: large polished star badge with layered radiant rings. |
| 11–14 | The Level 10 badge gains arcs, aura, layered rings, and controlled sparkle density. |
| 15 | Maximum level: strongest polished central star, layered radiant rings, and tidy orbiting sparkles. |

Generated with the built-in image generation workflow and optimized to 256 × 256 PNGs.
